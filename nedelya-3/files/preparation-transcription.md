# Подготовка к практике «Расшифровка аудио»

Сделай это дома, до занятия. Тогда на занятии мы тратим время на программу, а не на установку и скачивание. По моей оценке (не измерена) уйдёт 30–40 минут, из них часть скачивание.

На занятии ты вместе с Claude Code сделаешь программу, которая расшифровывает аудио в текст на твоём компьютере, научишь её записывать звук (свой голос и звонок) и упакуешь в приложение, которое открывается двойным щелчком. Запись никуда не отправляется.

## 1. Проверь компьютер

- **Mac или Windows.** На Mac получится всё. На Windows всё, кроме записи звука компьютера (звук собеседника из звонка) и сборки приложения: остаётся микрофон и запуск командой.
- **Свободное место: держи не меньше 3 ГБ.** Нужно около 1 ГБ (пакеты около 0,5 ГБ, две модели 0,2 ГБ, приложение 0,2 ГБ); остальное запас.
- **Версия macOS.** Яблоко → «Об этом Mac». Для записи звука компьютера нужна macOS 13 или новее (по моим знаниям; проверено только на 26). Если старее, микрофон и расшифровка работают, звук компьютера нет.
- **Рабочий ноутбук.** Если компьютером управляет ИТ-служба, запись экрана и системного звука может быть запрещена. Это узнаешь на занятии; микрофон и расшифровка работают и так.
- **Наушники.** Возьми с собой: в звонке без наушников микрофон запишет и собеседника из колонок.

## 2. Установи `uv`

`uv` ставит Python и все нужные пакеты сам. Отдельно ставить Python, `pip` или `ffmpeg` не нужно.

Открой терминал: на Mac — Cmd+Пробел, набери «Терминал»; на Windows — меню «Пуск», набери «PowerShell».

Mac:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Закрой терминал и открой заново. Проверь:

```bash
uv --version
```

Должна напечататься версия. Если «command not found», закрой терминал и открой ещё раз; не помогло — напиши преподавателю текст ошибки.

## 3. Проверь Claude Code

```bash
claude --version
```

Должна напечататься версия. Запусти `claude` в любой папке и убедись, что ты вошёл в свой аккаунт и он отвечает. Если нет, настрой Claude Code, как в прошлых практиках.

## 4. Hugging Face: аккаунт и токен

Hugging Face (huggingface.co) — сайт, где лежат нейросетевые модели. На занятии мы скачаем оттуда модель для расшифровки. Для маленьких моделей аккаунт технически не нужен, но мы всё равно пройдём этот путь: он понадобится для закрытых моделей в следующих практиках.

1. Зарегистрируйся на huggingface.co (личная почта). Подтверди почту по письму.
2. Открой Settings → Access Tokens → кнопка **New token** (в интерфейсе названия могут немного отличаться). Тип: **Read** (только чтение). Имя: например, `practice-laptop`. Создай.
3. Токен покажется один раз. **Токен — как пароль.** Не вставляй его в чат с Claude, в документы, в письма и на скриншоты.
4. Войди с этим токеном. Делай это **в обычном окне терминала, а не через Claude**:

```bash
uvx --from huggingface_hub hf auth login
```

   Выбери вход токеном («Paste an access token»), вставь токен, нажми Enter. Если спросит про git credential, отвечай `n`.
5. Проверь вход:

```bash
uvx --from huggingface_hub hf auth whoami
```

   Должно напечатать имя твоего аккаунта.

Если не получилось, не страшно: на занятии у нас на это шесть минут, поможем. Токен можно удалить после занятия: Settings → Access Tokens → Manage → Delete; на компьютере выход: `uvx --from huggingface_hub hf auth logout`.

## 5. Прогрев: скачай всё заранее

Преподаватель даст папку `starting-material`. Открой терминал в ней (на Mac: перетащи папку на значок «Терминал» или в Терминале набери `cd `, перетащи папку в окно и нажми Enter) и запусти:

```bash
uv run warm-up.py
```

Скрипт скачает пакеты и обе модели (`tiny` и `base`). У меня на чистом кэше это заняло 46 секунд, у тебя может быть дольше: зависит от интернета, и если Python на компьютере нет, `uv` сначала скачает его (это я не измерял). В конце должно появиться «Всё готово: пакеты и обе модели на этом компьютере». Если появилось предупреждение про «unauthenticated requests», это не ошибка: так Hugging Face напоминает про вход.

## 6. Микрофон

Системные настройки → Звук → Ввод: выбери микрофон, которым будешь пользоваться. Если рядом лежит iPhone, он может сам предложить себя как микрофон: выбери встроенный, если не нужен другой.

## Безопасность

- Токен — как пароль (см. выше): не показывать, не пересылать.
- На занятии записываем только себя и тестовые записи. Записи с клиентами банка и рабочие звонки не использовать: даже на своём компьютере это чужие слова и персональные данные.
- Запись разговора с другим человеком — только с его согласия. Предупреждай участников.
