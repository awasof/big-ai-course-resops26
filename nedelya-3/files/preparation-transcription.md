# Подготовка к четвергу: расшифровка на вашем компьютере

Сделайте это дома, до четверга, 5 ноября. Тогда на занятии мы сразу делаем программу, а не ставим и скачиваем.

Всё делается в обычном окне Claude Code или Codex — промптами, команды набирать не нужно. Займёт около 30 минут, часть из них — скачивание. Те же шаги со скриншотами — на сайте курса, в «Домашке» недели 3 (ДЗ-2).

В четверг вы вместе с агентом соберёте программу, которая расшифровывает аудио в текст прямо на вашем компьютере. Запись никуда не отправляется.

## 1. Папка проекта

1. Скачайте `starting-material.zip` и распакуйте.
2. На рабочем столе создайте папку `transcribe` и переложите в неё всё из распакованной папки.
3. Откройте `transcribe` в агенте:
   - Claude: вкладка Code → Local → Open folder… → `transcribe`;
   - Codex: приложение ChatGPT → Codex → выберите папку `transcribe`.

В этой же папке работаем в четверг.

## 2. uv

uv — программа, которая сама ставит Python и библиотеки. Вставьте промпт:

```
Проверь, установлена ли у меня программа uv: uv --version. Если её нет — установи uv с официального сайта docs.astral.sh/uv тем способом, который там указан для моей системы. Потом проверь, что uv --version печатает версию, и покажи её. Больше ничего не ставь и не меняй.
```

Агент будет спрашивать разрешение на команды — разрешайте. В конце он покажет версию uv.

## 3. Аккаунт на Hugging Face

Hugging Face — сайт, откуда скачивается модель для расшифровки. Откройте huggingface.co в браузере → Sign Up, зарегистрируйтесь и подтвердите почту по письму.

## 4. Файл для токена

Токен — это пароль для программ, его покажут один раз. Чтобы сразу было куда его положить, вставьте промпт:

```
Создай на рабочем столе пустой файл hf-token.txt — простой текст — и открой его в стандартном текстовом редакторе: я вставлю туда токен и сохраню. Сам в файл ничего не пиши.
```

## 5. Токен

1. На huggingface.co нажмите на свой аватар справа вверху → **Access Tokens**.
2. Нажмите **+ Create new token**.
3. Тип — **Read**. Имя — любое, например `big-ai-researchops-course`. Нажмите **Create token**.
4. В окне с токеном нажмите **Copy**, вставьте токен в открытый файл `hf-token.txt` и сохраните (Cmd+S на Mac, Ctrl+S на Windows).

После закрытия окна токен больше не покажут: потеряли — создайте новый. **Токен — как пароль.** В чат с агентом, в письма и на скриншоты его не вставляем.

## 6. Вход на Hugging Face

Вставьте промпт:

```
Войди в Hugging Face токеном из файла hf-token.txt на рабочем столе. Не показывай токен в чате и не выводи содержимое файла: подставь его прямо в команду, например uvx --from huggingface_hub hf auth login --token "$(cat ~/Desktop/hf-token.txt)". Потом проверь вход командой uvx --from huggingface_hub hf auth whoami и скажи, под каким именем я вошёл.
```

Получилось, если агент пишет «Login successful» и называет ваше имя на Hugging Face.

В ответе может быть строка про git credentials helper. Это нормально: она значит, что токен не записан для git. Git — программа, которая хранит версии файлов. В этой папке его ещё нет, заведём его в четверг первым шагом. Hugging Face через git мы не используем.

## 7. Что внутри warm-up.py

Сначала просим агента объяснить файл, ничего не запуская. Так стоит делать с любым скачанным скриптом: сначала понять, потом соглашаться.

```
Найди в этой папке файл warm-up.py. Ничего не запускай. Прочитай его и объясни простыми словами: что он сделает на моём компьютере, что и откуда скачает, сколько места это займёт и чего он не делает.
```

Чего ожидать: скрипт скачает библиотеки — около полугигабайта: распознавание речи faster-whisper и блоки для записи звука — и две модели расшифровки с Hugging Face, `tiny` и `base`, вместе 216 МБ. Потом проверит, что модели открываются. Всё ляжет в общий кэш компьютера, в папке ничего не появится. В четверг программа возьмёт это оттуда, без ожидания.

## 8. Запуск

Всё понятно — вставьте промпт и разрешите команду:

```
Запусти uv run warm-up.py в этой папке и дождись конца — первый раз это несколько минут. Покажи последнюю строку. Если будет ошибка — покажи её текст и объясни простыми словами, ничего не меняя в файлах.
```

Ждём строку «Всё готово: пакеты и обе модели на этом компьютере». Если агент пишет, что uv не найден, закройте приложение и откройте снова.

## 9. По желанию: большая модель medium

Прогрев скачал две маленькие модели, `tiny` и `base`: они быстрые, но ошибаются чаще. Если хотите в четверг попробовать модель побольше, скачайте заранее `medium` — 1,5 ГБ, нужно ещё около 2 ГБ свободного места. Вставьте промпт:

```
Хочу заранее скачать большую модель распознавания medium. Сначала проверь, сколько свободного места на диске, и скажи мне: нужно хотя бы 3 ГБ. Если хватает — запусти в этой папке uv run warm-up.py medium и дождись конца: модель весит 1,5 ГБ, это может занять несколько минут. Покажи последнюю строку.
```

Ждём строку «Всё готово: пакеты и модели tiny, base и medium на этом компьютере». В четверг, чтобы работать с ней, скажите агенту: «добавь в выбор модели medium».

## 10. Наушники

Возьмите на занятие наушники — проводные или беспроводные, без разницы. Программа записывает звонок двумя каналами: ваш голос — с микрофона, голос собеседника — из звука компьютера. Если собеседник звучит из колонок, микрофон запишет его ещё раз, поверх вашего голоса. Микрофон настраивать не нужно: подойдёт встроенный в ноутбук.

## Чек-лист: вы готовы, если

- [ ] Агент показал версию uv.
- [ ] Агент вошёл на Hugging Face и назвал ваше имя.
- [ ] `warm-up.py` дошёл до «Всё готово».
- [ ] Под рукой наушники.

## Что важно знать

- На Windows работает всё, кроме записи звука компьютера (голоса собеседника из звонка) и сборки приложения. На Mac звук компьютера записывается с macOS 13 и новее.
- Если ноутбуком управляет ИТ-служба, запись системного звука может быть запрещена. Микрофон и расшифровка работают и так.
- Записываем только себя и тестовые записи. Записи с клиентами и рабочие звонки не используйте: это чужие слова и персональные данные. Разговор с другим человеком — только с его согласия.
- Токен можно удалить после курса: аватар → Access Tokens → у токена три точки → Delete.

## Если что-то не получилось

Напишите до четверга: на каком шаге остановились и какой текст ошибки увидели. Токен в сообщение не вставляйте.
