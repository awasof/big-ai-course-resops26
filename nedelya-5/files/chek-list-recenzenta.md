# Чек-лист рецензента анкеты

Шесть групп. По каждой — найдено или «проблем нет». У каждого замечания — серьёзность: критично · важно · мелочь.

## 1. План
- [ ] У каждого вопроса есть «зачем» — какой исследовательский вопрос он закрывает
- [ ] Каждый исследовательский вопрос закрыт хотя бы одним вопросом анкеты и одним сравнением
- [ ] Нет вопросов «на всякий случай»: вопрос без «зачем» вычёркивается
- [ ] Для каждого сравнения из плана в анкете есть обе группы и метрика

## 2. Формулировка
- [ ] Нет двойных вопросов: одна мысль — один вопрос, без «и» в середине
- [ ] Нет наводящих слов: «удобно ли», «правда ли», «наверное, вы…»
- [ ] Вопрос по сути, а не «согласны ли вы, что…»
- [ ] Слова — из словаря продукта; запрещённых слов нет; жаргона, который аудитория может не знать, нет
- [ ] Период короткий и конкретный: «за последний месяц», а не «обычно»
- [ ] Спрашиваем об опыте самого человека, а не о «людях вообще»
- [ ] Чувствительные темы (деньги, здоровье, доход) — с вариантом не отвечать и не в начале
- [ ] Не заставляем человека считать в уме

## 3. Варианты ответа
- [ ] Варианты не пересекаются (возрастные группы, суммы, частота)
- [ ] Варианты покрывают всех; есть «Другое», где список может быть неполным
- [ ] «Затрудняюсь ответить» — только там, где он нужен по смыслу
- [ ] «Не пользовался» — отдельным вариантом или фильтром, а не «затрудняюсь»
- [ ] «Ничего из этого» в мультивыборе исключает остальные варианты
- [ ] Служебные коды одинаковые: 96 «Другое», 97 «Другое (впишите)», 98 «Ничего из перечисленного», 99 «Затрудняюсь ответить»
- [ ] Списки без порядка перемешиваются, «Другое» и «Ничего» закреплены внизу

## 4. Шкалы
- [ ] Подписаны все деления
- [ ] Число делений: согласительная — 5; шкала, где подписи называют признак, — 5–7
- [ ] Направление одинаковое во всей анкете
- [ ] Цифры совпадают со смыслом подписей (5 — «очень доволен», а не наоборот)
- [ ] Шкалы не перемешиваются
- [ ] Стандартные метрики — в канонической формулировке

## 5. Логика показа
- [ ] У каждого вопроса записано, кому он показан
- [ ] Нет тупиков: из каждого ответа есть путь дальше
- [ ] Нет вопросов, которые не увидит никто
- [ ] Нет подстановки (пайпинга) из пустого ответа
- [ ] Фильтрующие вопросы стоят вместе и раньше вопросов, которые от них зависят
- [ ] Открытый вопрос — до закрытых на ту же тему
- [ ] Сплит: группы делятся случайно, остальная анкета у них одинаковая

## 6. Длина и устройство
- [ ] Время прохождения — в пределах ограничения брифа (ориентир — до 15 минут)
- [ ] С телефона — без больших матриц, по одному вопросу на экран для шкал от 7 делений
- [ ] Число открытых вопросов — не больше ограничения брифа
- [ ] Сложное и чувствительное — не в начале

## Итог
- Критично: ⟪N⟫ · важно: ⟪N⟫ · мелочь: ⟪N⟫
- Решения по каждому замечанию — исследователь, правки по одной; решения — в журнал
