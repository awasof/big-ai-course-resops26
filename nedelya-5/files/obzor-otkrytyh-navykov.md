# Открытые навыки для количественных исследований

Обзор на 16 ноября 2026 года. Проверены доступность и содержимое файлов SKILL.md на GitHub; сами сторонние навыки не устанавливались и на данных «Нейрона» не запускались. Это подборка по устройству инструкций, а не независимый рейтинг качества результатов

## 1. Проектирование анкеты

[Survey Design — SSiertsema](https://github.com/SSiertsema/claude-code-plugins/blob/main/survey-design/skills/survey-design/SKILL.md)

Навык связывает исследовательские вопросы с вопросами анкеты, описывает коды ответов и переходы, предлагает таблицу проверки формулировок. Особенно полезна строка «исследовательский вопрос → вопросы анкеты»: по ней видно, что именно не покрыто

**Для нашего цикла:** продолжать показывать эту связь в спецификации и проверке. Расширенный промпт первого шага помогает заранее выделить решения и неизвестное

**Ограничение:** в примере есть NPS, готовые настройки набора и фиксированные ограничения на анкету. В наш цикл это не переносим: опираемся на бриф и решения исследователя

## 2. Анализ результатов опроса

[Survey Analysis — product-on-purpose](https://github.com/product-on-purpose/pm-skills/blob/main/skills/measure-survey-analysis/SKILL.md)

Навык предлагает описывать, кто планировался и кто действительно ответил, а рядом с результатом указывать, чего данные не показывают. Отдельно отмечает гипотезы, которые анкета фактически не проверяла

**Для нашего цикла:** в карточках выводов полезно явно показывать ограничение и связь с вопросом анкеты. На примере «Нейрона» это особенно важно: в учебной анкете обнаружено расхождение между планом измерять частоту по сценариям и вопросом о самом факте использования

**Ограничение:** автор использует готовые численные границы для оценки малых групп. Не переносим их как универсальное правило; достаточность данных и практическую значимость обсуждает исследователь

## 3. Кодирование открытых ответов

[Text Classification — open-science-skills](https://github.com/scdenney/open-science-skills/blob/main/codex/text-classification/SKILL.md)

Навык подробно описывает кодбук: название и определение кода, пограничные случаи, исключения и положительные и отрицательные примеры. Он предлагает явно решить, можно ли присвоить ответу несколько кодов, и уточнять кодбук по разногласиям

**Для нашего цикла:** проверить, чтобы при разборе открытых ответов участники видели не только примеры для кода, но и похожие случаи, которые в него не входят. Решение об одном или нескольких кодах оставляем исследователю

**Ограничение:** в остальной части навык обсуждает API, модели и собственные пороги для дополнительных проверок. Для нашего занятия используем разметку небольших пачек без API и не вводим эти пороги автоматически

## 4. Подготовка выгрузки

[Survey Data Processing — wentorai](https://github.com/wentorai/research-plugins/blob/main/skills/analysis/wrangling/survey-data-processing/SKILL.md)

В файле есть программные примеры для сводки пропусков, времени прохождения и перекодировки. Можно посмотреть, как автор превращает диагностику выгрузки в воспроизводимый код

**Для нашего цикла:** полезна сама идея проверяемого отчёта о пропусках и времени, но расчёты необходимо сверять с картой данных и маршрутами анкеты

**Ограничение:** примеры задают произвольные пороги времени и полноты, содержат проверочные вопросы и жёсткие границы для каппы. Не копируем их как правила исследования. Быстрый ответ — сигнал для обсуждения; исключение возможно только после подтверждения конкретного правила исследователем

## Что можно добавить в следующей итерации

1. В проверке анкеты показывать таблицу покрытия: решение → исследовательский вопрос → вопрос анкеты → показатель; отмечать непокрытые связи
2. В карточке вывода добавлять строку «что эти данные не позволяют утверждать» и ссылку на вопрос или таблицу
3. В примере кодбука показывать пару соседних категорий, пограничный ответ и объяснение, почему он относится к одной из них

Эти идеи предлагаются для обсуждения и дальнейшей проверки на учебном примере. Сторонние инструкции и код не включены в набор навыков курса
